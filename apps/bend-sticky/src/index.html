LAWS.bend — human-owned rules

Laws are precise specs, not prompts. LAWS.bend imports your code and states what must always hold. Agents should not edit this file without you.

  • add_zero — adding zero is identity on Nat
  • pow2_base — pow2(0) == 1
When using Bend:
• run bend guide to learn it
• use LAWS.bend to keep important rules
• run bend PROOF.bend before committing
• parallelize the code whenever possible

PROOF.bend — the commit gate

PROOF.bend imports LAWS.bend and discharges each law with a matching def Laws.<name>. When every proof checks, Bend prints All terms check. 

Click “Run bend PROOF.bend”

Automatic parallelism — pow2

Bend has no threads and no locks. A parallel call like a b = pow2(p) pow2(p) tells the runtime both recursive branches are independent; the scheduler spreads them across cores (or GPU with !). 

Click “Run bend parallel.bend”
